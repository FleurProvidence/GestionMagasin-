# Maquettes des interfaces — GestionMagasin

Cette maquette est un prototype visuel statique et autonome, rédigé en HTML/CSS/JavaScript sans dépendance externe.

## Ouvrir la maquette

Ouvrir `index.html` dans un navigateur. La navigation permet de passer entre les écrans :

- Tableau de bord
- Produits
- Stock
- Ventes
- Rapports
- Paramètres
- Connexion

Les chiffres et exemples affichés sont fictifs. Les boutons servent à illustrer l’interface et ne réalisent pas d’opérations sur les données du projet.
